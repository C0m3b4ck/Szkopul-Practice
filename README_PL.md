## Wymagania
- Kompilator C++ (zalecany g++)

## Instalacja
1. Sklonuj repozytorium:
   ```
   git clone https://github.com/C0m3b4ck/Szkopul-Practice.git
   ```
2. Skompiluj dowolne rozwiązanie:
   ```
   g++ -O3 -static ścieżka/do/pliku.cpp -std=c++17 -o prog && ./prog
   ```
3. Uruchom z danymi wejściowymi:
   ```
   ./prog < input.txt
   ```
